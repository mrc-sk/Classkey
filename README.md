# Classkey（启课）

一个面向老师与学生的轻量作业与成绩平台。老师用邮箱注册并绑定重要通知手机号；**学生无需注册、无需手机号**，由老师创建账号并派发密码。

以 **GNU GPL v3.0** 协议开源，详见 [LICENSE](LICENSE)。

## 能做什么

- **老师**：邮箱注册、绑定手机号与学校/年级/班级；批量建学生账号、导出密码表、重置密码
- **作业**：全班或指定学生派发；在线作答 / 上传附件 / 只留不交；截止日期与补交开关；题库客观题自动判分；批改打分与评语
- **成绩**：直发学生账号，或生成「成绩代号 + 查看密码」让学生自行解锁（密码只存哈希）；成绩分析、分数段分布、个人趋势、成绩单打印
- **通知**：新作业 / 批改完成 / 新成绩自动推送，截止前自动提醒；公告栏与师生留言
- **更多**：多班级与班级码、家长只读链接、两步验证、操作审计、自动备份、深色模式、PWA、全局搜索、月历与多语言

## 本地运行

需要 Python 3.10+（开发验证环境 3.14.7）：

```bash
pip install -r requirements.txt
python app.py
```

打开 `http://127.0.0.1:5173`。Windows 可直接双击 `start.bat`；局域网与 HTTPS 用 `https_start.bat`（依赖本机 openssl 生成自签证书）。

## 演示数据

| 身份 | 邮箱 | 密码 |
|---|---|---|
| 老师 | `teacher_demo@qike.local` | `Teach12345` |
| 学生 | `liming@qike.local` | `NewPass12345` |

删除 `data/qike.db` 并重启即可清空演示数据。**正式部署前务必删除演示账号、重置密钥并启用 HTTPS。**

## 安全说明

登录密码与成绩查看密码均以哈希保存；CSRF 校验、登录失败限流、上传类型与 10MB 白名单、跨角色越权校验、CSP 安全响应头、可选 Secure Cookie。短信 / 邮件只提供 Webhook 接口，不内置服务商。
